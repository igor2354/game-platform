# Бег, ходьба и спринт при движении назад

При беге, ходьбе на Ctrl и движении в приседе на C герой сохраняет взгляд
и оружие по направлению курсора. Если A/D задают противоположное направление,
применяется множитель движения задом. Цикл кадров тела идёт в обратном порядке
и зависит от фактически пройденного расстояния.

**Только активный спринт** на Shift разворачивает героя лицом по движению.
Оружие переносится перед телом с небольшим наклоном ствола вниз, обе руки
сохраняют хват. При отпускании Shift, истощении запаса, прицеливании или стрельбе
герой возвращается к курсору. Спринт сохраняет свою полную базовую скорость;
штрафа движения задом у него нет.

Камера продолжает использовать независимое направление курсора. Временный
разворот спринта не переключает знак упреждения камеры. Дэш из спринта фиксирует
разворот корпуса и оружия по направлению самого дэша до завершения действия,
даже если отпустить Shift. Он использует восемь кадров обычного дэша с
зеркальным отображением для движения влево. Обычный дэш назад вне спринта
сохраняет свою отдельную анимацию и фиксированное направление перемещения.

## Настройки F3 → «Движение задом»

| Ползунок | По умолчанию | Диапазон | Скорость задом на ровном полу |
|---|---:|---:|---:|
| Скорость бега задом | 0,7× | 0,1–1× | 224 px/с при беге 320 |
| Скорость ходьбы задом | 0,8× | 0,1–1× | 112 px/с при ходьбе 140 |
| Скорость в приседе задом | 0,8× | 0,1–1× | 115,2 px/с при приседе 144 |

Числовой ввод и ползунок связаны; изменения действуют сразу на земле.
Значение 1× убирает штраф заднего хода для выбранного режима. Присед использует
свой отдельный множитель; удержание Ctrl вместе с C не удваивает замедление.

![Настройки движения задом](../../../../5_Проверки%20и%20отчёты/Полигон/core/backward_movement_settings.png)

Итоговая скорость определяется умножением:

`скорость режима × множитель движения задом × замедление стрельбой × множитель склона`

Для приседа скорость режима равна скорости бега, умноженной на скорость приседа.
Пример бега задом по умолчанию: `320 × 0,7 = 224 px/с`;
при непрерывной стрельбе от бедра `224 × 0,65 = 145,6 px/с`,
при прицеливании `224 × 0,3 = 67,2 px/с`. Подъём и спуск меняют эти скорости
по общим настройкам склонов. Передвижение вперёд сохраняет базовую скорость.

Прыжок наследует фактическую скорость выбранного направления. Полный прыжок
задом с бега короче прыжка вперёд, при той же высоте. Множитель заднего хода
сохраняется вместе со скоростью отталкивания: поворот курсора в воздухе
не увеличивает уже начатый прыжок.

Новые значения сохраняются в профиле F3 и общем JSON из 121 значения.
Ключи: `run_backward_multiplier`, `slow_walk_backward_multiplier`,
`crouch_backward_multiplier`. Старые JSON-файлы получают значения по умолчанию;
прежние скорости движения и параметры стрельбы сохраняются.

Проверки: `tests/backward_movement_smoke.gd`, импорт и экспорт —
`tests/settings_file_smoke.gd`. Скриншоты и базовый JSON воспроизводятся
через `tools/capture_backward_movement.gd`.
