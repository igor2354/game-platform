# Ходьба стоя

Удерживайте **Ctrl** вместе с A/D или стрелками. Без Ctrl герой бежит;
Shift включает ограниченный спринт. **C** сохраняет приседание и запускает
подкат новым нажатием во время разогнанного спринта.

По умолчанию ходьба — 140 px/с, бег — 320 px/с, спринт — 520 px/с.
Ctrl имеет приоритет над Shift, запас спринта при ходьбе восстанавливается.
Ctrl не меняет высоту тела: герой остаётся стоять с коллизией 64 px.
Если одновременно удерживается C, действует обычная скорость приседа;
дополнительного замедления от Ctrl нет.

## Настройки F3 → «Ходьба»

| Параметр | По умолчанию | Диапазон |
|---|---:|---:|
| Скорость ходьбы | 140 px/с | 40–750; не выше скорости бега |
| Разгон ходьбы | 1000 px/с² | 200–6000 |
| Торможение ходьбы | 1800 px/с² | 200–8000 |
| Управление в воздухе | 900 px/с² | 200–4000 |
| Дальность прыжка · ходьба | 1× | 0,25–2× |
| Шум шагов при ходьбе | 0,5× | 0–3× |

У каждого параметра есть ползунок и точный числовой ввод. Настройки действуют
сразу, сохраняются в профиле F3 и входят в общий JSON из 121 значения.
Панель показывает расчётную дальность прыжка, разгон и тормозной путь.
При уменьшении скорости бега скорость ходьбы также ограничивается;
оба элемента ввода обновляются вместе.

![Ходьба в настройках](../../../../5_Проверки%20и%20отчёты/Полигон/core/standing_walk_settings.png)

Прежняя вкладка «Ходьба» переименована в **«Бег»**. Старые ключи `run_speed`
и `walk_jump_multiplier` сохраняют свои значения: скорость бега и его множитель
прыжка. Новые параметры используют префикс `slow_walk_`. Старые JSON-файлы
получают новые значения по умолчанию, сохраняя прежние настройки бега.

## Взаимодействие с механиками

Замедление на подъёме и ускорение на спуске берутся из общей вкладки «Склоны».
Стрельба от бедра и в прицеле дополнительно замедляют ходьбу своими
множителями; работают автоматический и одиночный режимы. В прицеле скорость
по умолчанию составляет 42 px/с, руки продолжают держать оружие у глаз.

Прыжок наследует скорость и множитель выбранного при отталкивании режима.
По умолчанию расчётная дальность прыжка с ходьбы — около 106 px, высота
совпадает с бегом и спринтом. Нажатие или отпускание Ctrl в воздухе
не меняет скорость уже начатого прыжка. После приземления учитывается
текущий ввод. Лестница сохраняет собственную скорость; после наземного
дэша герой возвращается к ходьбе, если Ctrl удерживается.

Тело использует отдельные восемь запечённых кадров `walk.png` с коротким
шагом, невысоким переносом стопы и постоянной опорой на землю. Цикл зависит
от пройденного пути, движению назад соответствует обратный порядок кадров.
Руки с оружием остаются сегментными. Генератор — `tools/bake_core_hybrid.py`.

Проверка: `tests/standing_walk_smoke.gd`; совместимость профилей и JSON —
`tests/settings_file_smoke.gd`. Скриншоты и базовый JSON:
`tools/capture_standing_walk.gd`.
