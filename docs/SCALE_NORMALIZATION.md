# София 1,00×: новая база размеров и телеметрии

**2026-10-25 · Godot 4.7.2 / Windows / GL Compatibility.**
Прямое поручение пользователя: закрепить правила локаций, считать прежнюю
Софию 2,85× новой Софией **1,00×**, обновить измерения и телеметрию.
Физический герой не уменьшался; концепт, PNG, анатомия и анимации не менялись.

## Код и профили

**Уточнение 2026-10-26:** шесть расстояний ручного паркура также приведены
к мировой базе Софии 1,00× после обнаруженного отказа захвата. У них отдельный
`parkour_basis_version=2`; старые CFG/JSON без поля переводятся один раз с
коэффициентом 2,85. Общая `scale_basis_version` остаётся 2. Не переводить
повторно ни движения, ни ручные параметры. [Причина и проверки](CORE_PARKOUR.md).

`character_scale()` и `request_character_scale()` работают с новой пользовательской
базой. `body_scale` остаётся внутренним трансформом старой координатной сетки
рисунка: 2,85 у исходника означает пользовательские 1,00× у Софии. Сохранение
этого трансформа позволяет не переразмечать риг/оружие и не менять внешность.
Не использовать его как ростовой коэффициент для новых чертежей или профилей.

Movement/camera CFG и разделы общего JSON имеют `scale_basis_version=2`.
Старые файлы без поля считаются версией 1; при загрузке/импорте выполняется:

- `player_scale` /2,85; 2,85 становится 1,00;
- 21 скорость/ускорение, четыре локальных габарита и ширина автопаркура ×2,85;
- два времени ручного паркура /2,85, а runtime делит их на нормализованный
  коэффициент движения: фактическая длительность сохраняется;
- отношения, остальные длительности, здоровье, камера/её кадрирование и мировые
  расстояния ручного захвата не перемножаются.

Прежний физический диапазон ползунка также сохранён: в новой записи это
примерно 0,175–1,404× вместо старых 0,5–4,0×; точность ввода 0,01×.

В новой базе сохранённые величины не пересчитываются повторно. Старые частичные
JSON дополняются новыми defaults только после пересчёта предоставленных полей.
Неизвестная версия отклоняется до применения импорта. Сравнение дробных
сохранённых значений допускает обычную погрешность текстового float до 10⁻⁶.

Миграция CFG при чтении сама файл не записывает. Для текущего пользователя
движение и камера намеренно сохранены через соответствующие кнопки F2;
исходные две копии и SHA256 пяти профилей сохранены вне игры. Три других CFG
не изменились. Новый ресурс движения тоже содержит мировые величины базы 1,00×.
Ввод F2 и CFG/JSON используют одну систему, а не разные числа для одинаковой скорости.

## Подписи и координаты

HUD: размер 1,00×; скорость и компоненты Vx/Vy — м/с / км/ч / ед./с;
координата X и высота H — м / ед.; g — м/с² / ед./с²; капсула В×Ш — м / ед.;
спринт/восстановление/готовность — секунды; дистанция дэша — м / ед.
H положительна вверх. Начало леса (12000,760), полигона (0,760).
Это координаты **от начала уровня**, а не абсолютные технические координаты сцены.

На карте ось X имеет те же м/ед. и адаптивный шаг. График разгона — м/с и
секунды с учётом фактического размера. Радиусы взрыва/волны и расстояния до
контактов показываются в м/ед. Экранные пиксели фильтров остаются пикселями;
углы и множители сохраняют градусы и безразмерные доли.

## Фактические проверки

Только София / STG-44; все автоматические сохранения — пять изолированных CFG.
Свежие целевые наборы:

- `normalized_sofia_scale_smoke.gd` **36/36**: старая/новая версия CFG/JSON,
  повторный импорт, размеры и скорости, новый коэффициент 1,20, независимость
  камеры/мира, отказ небезопасного роста под потолком, единицы HUD.
- `player_scale_smoke.gd` **109/109**: исходные физические размеры тестовых
  фикстур сохранены; стрельба/ствол, перезарядка, гранаты, присед, лестницы,
  предмет, паркур, рэгдолл/подъём и независимость камеры. Ввод/ожидания обновлены
  под новую базу и фактическое время разгона, без подмены мировых габаритов.
- `sprint_auto_parkour_smoke.gd` **75/75**: лестницы ver2, хват, автопаркур и профили.
- `tactical_ceiling_smoke.gd` **67/67**: потолки трёх сцен, полный/короткий прыжок,
  четыре скорости и устойчивые выходы/обратные спуски всех 17 лестниц ver2.
- `campaign_developer_smoke.gd` **99/99**: вкладки, числовой ввод, CFG/JSON,
  сохранение/загрузка. Одна ожидаемая ошибка намеренно испорченного временного CFG.

Всего **386/386 целевых проверок**; это не тестирование всего проекта.
