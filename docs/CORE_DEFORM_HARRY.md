# Гарри: анатомия по концепту и деформируемый рисунок

Сверка **2026-10-18**, Windows / Godot **4.7.2**, GL Compatibility.
Поручение: исправить пропорции Гарри, сохранив скелетную анимацию и деформацию
рисунка. Софию, в том числе её деформацию и подъём, не перерабатывать.

## Порядок построения

1. Исходный образ — [концепт пользователя](../source_art/campaign/harry-reference.jpg).
2. [harry_anatomy.gd](../scripts/campaign/harry_anatomy.gd) хранит разметку
   в координатах равномерного превью концепта 1440×1724. Диапазон от верхушки
   каски Y=180 до пола Y=1606 задаёт единый масштаб: 64/1426.
3. По разметке вычислены длины плеча **10,42404**, предплечья **9,80756**,
   бедра **16,38302**, голени **10,71928**, торса **22,79436**.
   Таз и колено частично скрыты шинелью: это реконструкция, не точное измерение
   невидимых суставов и не новый утверждённый пользователем эталон.
4. [harry_motion.gd](../scripts/campaign/harry_motion.gd) задаёт новые угловые
   движения. Сначала сглаживаются углы, затем строится поза с постоянными
   длинами. Прежняя таблица `resources/core/hybrid/poses.gd` не является
   источником поз для включённого нового Гарри.
5. Оружие, IK, лестницы и физика получают суставы этой анатомии.
   Высота капсулы не масштабирует изображение или кости Гарри.

Гарри по-прежнему использует **Skeleton2D, 13 Bone2D и восемь Polygon2D**:
корпус/шинель, голова, две цельные руки, две цельные ноги, два ботинка.
Это скелетная анимация рисунков, не переход на цельные покадровые циклы Софии.
Общий выбор игровых состояний и управление сохранены, размеры и движения
нового Гарри строятся отдельно. F5 выключает этот вариант и возвращает прежний
сегментный облик; его старые пропорции не объявляются исправленными.

## Исходники и привязка рисунка

Сохранены без растровой правки:
[harry_deform_v2.png](../resources/campaign/harry_deform_v2.png),
[character_parts.png](../resources/campaign/character_parts.png).
Корпус, цельный рукав, цельная штанина и три головы берутся из первого атласа;
ботинки — из второго. Эти рисунки созданы ранее по концепту;
[историческое происхождение](../source_art/campaign/harry_deform.json).

Каждая часть получает **равномерный масштаб по X/Y**, выбранный по концепту,
вместо прежней независимой подгонки ширины/высоты прямоугольника.
Высота изображения головы с шарфом/каской — **11,6690** вместо прежних 22;
изменение кадра головы сохраняет соотношение сторон его исходного изображения.
Шинель и ботинки калибруются отдельно по соответствующим видимым участкам
концепта, не по коллайдеру. Альфа-границы ботинка уточнены в UV, чтобы слабый
прозрачный фон не уменьшал фактический рисунок внутри прямоугольника.
Измеренная ладонь рукава `(854,610)` на атласе привязана к логическому хвату;
исходный PNG не переносился и не перерисовывался.

## Интеграция и физика

`hybrid_body.gd` выбирает новый путь только для `uses_deformed_skin()`.
Точки головы/шеи/таза и плеч берутся из новой анатомии; руки имеют её постоянные
длины. Посадка оружия использует их досягаемость и уменьшенную зону головы,
а не растягивает тело к оружию. Лестница выбирает достижимые перекладины.

Рэгдолл получает текущую новую позу. Для **Гарри** подъём дополнительно
восстанавливает постоянную длину торса и решает двухзвенные цепи рук/ног;
голова остаётся связана с шеей. Изменённый код ограждён проверкой Гарри.
Ветка подъёма и исходные рисунки Софии не исправлялись: её ранее найденное
изменение длин при подъёме остаётся отложенным по указанию пользователя.

F5 сохраняет прежние переключатели деформируемого облика, сетки, плавности
переходов и объёма суставов; CFG/JSON совместимы, новых полей нет.
Скорости, урон, оружейные характеристики и геометрия уровней не менялись.

## Проверки и визуальная приёмка

Новый `tests/harry_anatomy_smoke.gd` проверяет 960 сочетаний состояния/фазы/
стороны, постоянство костей, независимость от коллайдера, равномерный масштаб
каждого фрагмента, нарисованные ладони, хват лестницы и длины при подъёме.
На текущем прогоне **13/13**; максимальная ошибка длины около **0,00000461**.

Полный целевой прогон **2026-10-18**: `harry_anatomy` 13, `deform_harry` 33,
`character_pose_cache` 10, `sofia_anatomy` 52, `sofia_gait_down` 61,
`sofia_ladders_arms` 90, `campaign_flow` 90, `reload` 60, `ads_pose` 30,
`downward_aim_cache` 24 — **463/463** (имена без `_smoke.gd`).
Итоговые журналы без SCRIPT ERROR/ERROR/FAIL и предупреждений. Все пять реальных
CFG неизменны по SHA256 до/после. Это перечисленные сценарии, не весь проект;
старые числа проверок из опыта 17 октября сюда не складываются.
Дополнительно повторён аудит Софии **13/13**: её 100 кадров и прежнее изменение
длин при подъёме совпали с предыдущим результатом. Всего **476** целевых
проверок с этим аудитом. PNG Гарри/Софии и исходные скрипты `sofia_*` не изменены.
Журналы сохранены в [папке проверки](harry_anatomy_20261018/logs/).

[Инструмент снимков](../tools/capture_harry_anatomy.gd) использует временные
профили. Нативно сняты стойка/ADS/зеркало, ходьба, бег/спринт, присед и движение
в нём, прыжок, подкат, восемь фаз бега, падение и подъём:
[стойка](harry_anatomy_20261018/idle.png),
[прицеливание](harry_anatomy_20261018/ads.png),
[бег](harry_anatomy_20261018/run.png),
[присед](harry_anatomy_20261018/crouch.png),
[подъём](harry_anatomy_20261018/recovery.png).
Масштаб 7× задан только инструментом для осмотра, игровой диапазон F5 прежний.

Новый результат ещё **не утверждён пользователем как визуальный эталон**.
Исходные рисунки — отдельные ранее созданные фрагменты: полного совпадения
их деталей/ракурсов с концептом одним ригом гарантировать нельзя. Скрытые
суставы реконструированы, шинель не имеет отдельной симуляции ткани и может
пересекаться с ногами/полом в крайних позах. Точной фиксации стоп на земле
при любых скоростях пока нет. Это ограничения для визуального обсуждения,
а не разрешение менять исходные концепты. EXE/PCK и новые коммиты не создавались.
