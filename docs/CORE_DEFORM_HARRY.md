# Гарри: проба деформируемого рисунка в 2D

Сверка: **2026-10-17**, Windows, Godot **4.7.2**, GL Compatibility.
Пользователь поручил попробовать сочетание скелета, деформации рисунка и
отдельных нарисованных кадров; **3D исключён**. Первый опыт ограничен Гарри.
Гарри затем перенесён на полигон без замены его техники. София в прологе,
исходный герой при прямом запуске main.tscn и Z02 сохраняют прежнюю
отрисовку; только София на полигоне получила следующий опыт
[с рисованными фазами](CORE_SOFIA_CELS.md).

## Как посмотреть

Запуск → «Компания» → Гарри → «Выбрать» → любое оружие → «Применить».
Новый облик включён по умолчанию. В **F5 → «Визуал»**:

| Параметр | База | Назначение |
|---|---:|---|
| Гарри: деформируемый рисунок | Вкл. | Переключает новый и прежний облик; выключение не стирает параметры |
| Гарри: показать сетку деформации | Выкл. | Показывает треугольники поверх реально деформированного рисунка |
| Гарри: плавность перехода поз | 0,06 с | 0–0,20 с; ноль убирает сглаживание переходов |
| Гарри: объём локтей и коленей | 0,65× | 0–1,2×; корректирует ширину сетки при сгибе |

Ползунки имеют точный ввод. Все четыре значения входят в camera CFG и общий
JSON версии 1; старые профили получают базовые значения. Переключение
отрисовки работает и на паузе, включая физическое тело. Параметры не
меняют силу взрыва, коллизии, урон или движение героя.

## Что реализовано

- `scripts/campaign/deform_figure.gd`: настоящий **Skeleton2D с 13 Bone2D**,
  восемь Polygon2D с UV, явными треугольниками и нормированными весами.
  Каждый рукав и каждая штанина — цельный рисунок, сгибаемый двумя костями.
  Корпус/шинель деформируется между торсом и тазом; ботинки отдельные.
- Рисунок `resources/campaign/harry_deform_v2.png` содержит корпус, цельную
  руку, цельную ногу и **три отдельно нарисованных положения головы**:
  обычное, прицеливание, взгляд вверх. Голова меняет UV на той же сетке.
  Это ограниченная покадровая коррекция, **не новый полный набор рисованных
  циклов бега/прыжка для всего тела**.
- Скелет использует существующие игровые позы и IK рук. В циклах движения
  интерполируются восемь прежних ключевых поз; смена состояния сглаживается.
  Кисти продолжают следовать хватам оружия, перезарядке, гранате и предмету.
  Сетки рукавов находятся в прежних слоях рук относительно корпуса и оружия.
- При взрыве новый скелет получает текущую позу, сторону и рисунок головы.
  Затем его кости следуют **реальным частям общего рэгдолла**, а тот же
  рисунок деформируется поверх них. Оружие следует торсу.
- Выживший Гарри проходит через общий переход подъёма около **0,65 с**,
  с сохранением HP и проверкой места для полной стоячей позы. Новый удар
  прерывает подъём и возвращает физику; смерть оставляет физический труп.
  F8 восстанавливает Гарри на платформе пролога.

Точки интеграции: `campaign/player_skin.gd`, `core/hybrid_body.gd`,
`core/hybrid_arm.gd`, `core/player.gd`, `core/character_ragdoll.gd`,
`core/player_ragdoll_skin.gd`, `core/camera_settings.gd`,
`core/movement_overlay.gd` (все пути относительно `scripts/`).

## Границы качества

Это проверяемый прототип техники, не законченный анимационный набор.
Три головы переключаются дискретно. Для тела пока используются прежние
ключевые позы, поэтому их художественные недостатки не устранены автоматически.
При крайних сгибах возможно растяжение рисунка. У длинной шинели нет
собственных физических коллайдеров/ткани: подол может пересекать пол при
падении и подъёме. Само тело сталкивается с миром через прежние физические
части. Расчленение игрока и перенос нового облика на остальных персонажей
этим опытом не добавлены.

Рисунок создан/исправлен встроенным **ImageGen** по концепту Гарри;
исходные PNG сохранены без растровой обработки, выделение областей происходит
через UV в Godot. Ботинки взяты из прежнего `character_parts.png`.
[Промпты и происхождение](../source_art/campaign/harry_deform.json).
