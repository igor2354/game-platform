## Первый набор: стоя, патруль, преследование и одна атака

| Движение | Что должно читаться |
| --- | --- |
| Ожидание | Сутулость, скованность, небольшие судорожные движения |
| Обнаружение/тревога | Переключение внимания и напряжение перед действием; не новая обязательная задержка ИИ |
| Начало патрульного шага | Перенос веса из стойки в движение |
| Патрульный шаг | Медленный замкнутый цикл, работа обеих опор |
| Остановка после патруля | Возврат в ожидание без скольжения |
| Смена направления стоя/на шаге | Согласованный разворот и смена перекрытий |
| Разгон в преследование | Выход из текущего состояния в звериный бег |
| Преследование | Угрожающий звериный цикл, резкая пластика, не спортивный человеческий спринт |
| Остановка после преследования | Гашение движения у цели или при смене задачи |
| Выход из преследования в атаку | Подготовка опоры перед замахом |
| Подготовка и замах | Читаемое намерение ударить, нужный разворот корпуса |
| Вынос/удар | Резкое атакующее движение, сохранение длины руки |
| Контакт обычной атаки | Отличимая постановка при взаимодействии, согласование с попаданием; не QTE |
| Промах/пронос руки | Завершение движения без контакта, без необоснованного удержания |
| Возврат после атаки | Различать выход после контакта и промаха, где это требуется; переход в ожидание/преследование |

## Второй набор: звериная низкая поза

| Движение | Что должно читаться |
| --- | --- |
| Опускание в звериный присед | Перенос веса и сгиб корпуса/таза |
| Низкое ожидание | Яростная собранная поза, готовность к сближению |
| Движение в приседе | Самостоятельный низкий цикл с опорами рук/ног по выбранной постановке |
| Остановка и смена направления низко | Сохранение низкой опоры, согласованная работа сторон |
| Подготовка и толчок из приседа | Упреждение и начало резкого сближения |
| Низкий разгон → преследование | Связь с принятым беговым циклом без скачка корпуса |
| Возврат в стоячую позу | Достижимое распрямление с сохранением опоры |

Первоначальная звериная сидячая поза сохранена в требованиях. Решить по

не удалять и не производить второй одинаковый комплект.

## Третий набор: лёжа и доступные конечности

| Движение/условие | Что нужно поставить |
| --- | --- |
| Положение ничком | Основной лежачий образ и опоры |
| Ползание с обеими руками и ногами | Цикл подтягивания/переноса опор к обнаруженной цели |
| Остановка/смена направления лёжа | Поворот без телепортации и вращения неподвижной плоской фигуры |
| Ползание без одной ноги | Работа сохранившихся конечностей; проверить обе стороны |
| Ползание без обеих ног | Подтягивание руками и работа корпуса |
| Ползание без одной руки | Разные опоры при сохранённых/утраченных ногах, без отдельной полной модели на каждую комбинацию |
| Без обеих рук | Желаемое яростное бултыхание; возможность движения ногами и условия беспомощности ещё выбрать |
| Подготовка и атака лёжа | Выбрать способ атаки, дальность и допустимые опоры; не назначать механику по картинке |
| Завершение атаки лёжа | Разные последствия контакта/промаха при необходимости, возврат в ползание |
| Подъём из лежачей позы | Только если состояние и оставшиеся конечности позволяют; согласование с физическим восстановлением |

## Сопровождающие движения: готовятся с соответствующим набором

| Ситуация | Требуемая совместимость |
| --- | --- |
| Прерывание замаха/удара | Выход из текущей позы, отмена несостоявшегося урона |
| Локальная реакция на попадание | Ограниченная добавка поверх основного действия |
| Сильное отшатывание | Потеря равновесия/прерывание и конкретный выход |
| Падение | Переход из текущей видимой позы в физику |
| Отрыв конечности во время движения | Текущая сторона/положение, смена опор, часть не возвращается следующим рисунком |
| Восстановление после отшатывания/падения | Зависит от положения тела, направления воздействия и доступных опор |
| Смерть | Прекращение атаки/восстановления, переход в соответствующее состояние тела |

Это совместимость художественной основы с существующим поведением и будущими
реакциями. Новую систему характеристик оружия/брони не реализовывать вместе
со списком или первым набором. Разные виды восстановления не считать одной
универсальной анимацией. Реакции и смерть не обязательно требуют рисованного
покадрового клипа — часть задач выполняет физика/ограниченная процедурная добавка.

## Общее для всех наборов

Проверять вход, цикл/действие, выход и допустимое прерывание; обе стороны,
необходимые ракурсы и сменные детали. Не удваивать весь список ради направления
влево, но отдельно проверять асимметрию и повреждения. Пройденное расстояние,
масштаб и длина шага определяют поступательный цикл. Сначала короткая проба
рисковых разворотов/ползания, затем чистовая подготовка первого набора.
Выбор референсов не разрешает интегрировать собранный результат.

В этой задаче создан только перечень и ссылки на него. Проверки: соответствие
производственному плану, локальные ссылки, оформление; запусков игры нет.
