# Нуар: чёрно-белый мир и красные акценты

Реализовано и проверено **2026-10-23**, Godot 4.7.2, GL Compatibility.

В тот же день добавлена независимая [пикселизация](CORE_PIXEL_FILTER.md):
F5 → «Визуал», где выключатель нуара продублирован рядом с пикселизацией.
Обе обработки выполняются в одном проходе; нулевая сила нуара не отключает
пикселизацию. Ниже описаны исходный нуар и проверки его первого внедрения.

С **2026-10-24** также совместим с [низкоразрешённым миром](CORE_PIXEL_FILTER.md):
этот мир сначала увеличивается целыми пикселями, затем обрабатывается нуаром;
старая экранная пикселизация временно обходится. Прицел/маркеры теперь в
отдельном HD-слое 3, HUD и все меню остаются в полном разрешении.
Позднее добавленная «Сетка уровня» также обходит только старую экранную
пикселизацию, сохраняя нуар и его параметры.

## Включение и сохранение

**F5 → «Нуар»**, либо **F2 → Игрок → Камера и визуал → Нуар**.
Переключатель «Чёрно-белый нуар · красные акценты» действует сразу,
в том числе на паузе, на полигоне и в прологе. По умолчанию выключен.
Выключение сохраняет параметры; сила 0 также отключает обработку и копирование.

«Сохранить» в разделе камеры или «Сохранить всё» записывает значения
в прежний `core_camera.cfg`. Все 11 новых ключей входят в секцию `camera`
общего JSON версии 1. Шестого профиля нет. Старые CFG/JSON без новых ключей
оставляют нуар выключенным. Сброс возвращает базовые значения и выключенное
состояние, не перезаписывая сохранённый профиль.

## Параметры

Каждое число имеет ползунок и точный ввод.

| Параметр | По умолчанию | Диапазон |
|---|---:|---:|
| Сила фильтра | 1 | 0–1 |
| Контраст полутонов | 1,05 | 0,6–1,6 |
| Осветление полутонов | 1,05 | 0,5–1,8 |
| Свет в глубоких тенях | 0,045 | 0–0,2 |
| Предел яркости бликов | 0,86 | 0,55–1 |
| Сила красных акцентов | 1 | 0–1 |
| Диапазон красных оттенков | 12° | 2–40° |
| Мягкость отбора красного | 6° | 1–20° |
| Минимальная насыщенность красного | 0,45 | 0,1–0,9 |
| Яркость красного | 1,2 | 0,5–2 |

Монохром строится по яркости исходного цвета; контраст/гамма меняют полутона,
нижняя и верхняя границы смягчают тени/блики. Фактуру фильтр не перерисовывает.
Красный отбирается по цветовому тону, насыщенности и яркости, затем получает
алый оттенок с сохранением градаций яркости. Диапазон задаётся в обе стороны
от красного, мягкость — шириной плавного перехода за границей.
Сила акцентов 0 даёт полный монохром. Узкий отбор уменьшает попадание кожи,
оранжевого и коричневого в красную область. Это не семантическая маска:
любой подходящий по цвету предмет выделяется независимо от игрового смысла.
В полностью сером исходнике новые красные области сами не появляются.

## Устройство и границы влияния

[CoreNoirFilter](../scripts/core/noir_filter.gd) использует
[шейдер](../shaders/core_noir.gdshader). Подключение —
[CoreMovementLab](../scripts/core/movement_lab.gd), параметры —
[CoreCameraSettings](../scripts/core/camera_settings.gd), UI —
[CoreMovementOverlay](../scripts/core/movement_overlay.gd).
Мир рисуется в слое 0, фильтр — CanvasLayer 1, HUD — слой 2.
Панель разработчика, карта, прицел и меню находятся выше фильтра.
Фильтр не перехватывает мышь, не меняет управление, камеру или анатомию;
он независим от выключателя эффектов героя и не меняет исходные текстуры.
Явный BackBufferCopy перед фильтром обновляет буфер после мира, даже когда
CanvasGroup блюра героя уже читал экран. При выключении копирование отключено.

Поручение пользователя опирается на
[мягкий монохром](../../../../2_Локации/Проектирование/mvp_village/Кандидаты/sin_city_noir_2026-10-23/soft_noir_v2/Вложения/user_reference_2026-10-23.png)

Это направление обработки, не утверждение нового игрового фона.

Позднейшим отдельным поручением подключён лесной фон для проб в начале пролога;
его статус, размещение и проверки — в документе пикселизации.

`disabled`, `enabled`, `red_disabled`, `restored` сняты при одной камере
с одинаковыми цветовыми плашками и UI. Плашки существуют только в тесте.
`gameplay_noir.png` — чистый полигон; `developer_noir.png` — место включения.
Снимки проверок не являются утверждёнными художественными эталонами.

## Фактические проверки

**403/403** в семи наборах: нуар с окном **33**, developer **94**,
campaign developer **94**, JSON **88**, переключатели **48**, блюр **17**,
камера **29**. Тест нуара — [noir_filter_smoke.gd](../tests/noir_filter_smoke.gd).
Проверены UI, CFG/JSON, старые профили, пауза, отключение без сброса,
цвета реального шейдера, неизменность UI, CanvasGroup перед фильтром,
возврат исходных цветов и подключение в прологе.
Дополнительный headless-прогон нуара **17/17** повторяет часть оконного
и не прибавлен к 403. Нативные снимки просмотрены.
В двух developer-наборах намеренно подаётся повреждённый временный CFG:
ожидаемая ConfigFile parse error сопровождается успешной проверкой отказа
от частичной загрузки. Других ошибок финальных прогонов нет.
Проверка ресурсов: **63 медиа, 155 путей, 0 ошибок**. Реальные **5/5** CFG
неизменны по SHA256; сохранение и импорт в тестах перенаправлены во временные
файлы. Это не полный прогон проекта, не замер производительности разных GPU
и не проверка комфорта длительной игры.
