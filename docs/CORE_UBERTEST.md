# UBERTEST — внешний локальный тестировщик

Сверка 13.11.2026. Программа — `../UBERTEST`, запуск `Start.cmd`.
Поручение автономного тестировщика полностью ещё не завершено.

После замечания пользователя заменена подмена настроек: каждый запуск копирует
пять личных CFG в папку прогона и загружает копии. Перезапись оригиналов
исключена путями настроек; в тесте проверены хеши. Все пять фактически
применённых ресурсов совпали с загрузкой снимков штатными загрузчиками.
Оружейный CFG применяется после equip каталога, до первого игрового тика.
По умолчанию баланс не переопределяется. Интерфейс читает реальные значения
через отдельный inspect-only процесс; изменения включаются явно.
Несохранённые настройки другого процесса не синхронизируются.

Найдена причина чрезмерных прыжков: предыдущий адаптер задавал бег 912 и прыжок
2052 вместо сохранённых 327,75/342. Исправленный 6-секундный прогон использовал
327,75/342 и урон 35/15; случайных выстрелов 0. Это не проверка полного маршрута.

Пользователь уточнил: названия профилей означают тактику, не буквальную
агрессию/случайность. Удалены случайные огонь, прыжки по таймеру и перезарядка.
`../UBERTEST/bot_policy.gd` выделен без доступа к игровым узлам: дистанция,
наведение, очереди, оценка преграды, продвижение. Восприятие пока оценивает
лишь изменение кадра; распознавания противников и финиша нет. Поэтому стрельба
без подтверждённой цели запрещена. Боевые различия проверены только на
синтетических наблюдениях; полноценные тактические профили в игре не готовы.
Две короткие попытки прыжка при остановке кадра — эвристика, не навигация.
Телеметрия/координаты и геометрия поступают в отчёт, не в решения бота.

Симуляция принудительно оконная, с рамкой/изменением размера, без always-on-top;
панель: остановка/выход, пауза, фон, сворачивание, полный экран/окно.
Основное окно может остановить, поставить на паузу, вернуть игру из фона.
Обычное сворачивание приостанавливает симуляцию: иначе рендер застывает.
Фон — рендерящее окно вне экрана с NO_FOCUS и без захвата/warp системной мыши.
Ускорение 1–4× увеличивает physics Hz пропорционально; это не FPS-бенчмарк.

Текущий адаптер `tools/ubertest_runner.gd` запускает только Полигон 3D
из исходников. Обычная игра его не загружает. Другие карты и готовый EXE
не подключены. Карта — BoxMesh, без склонов; JSON/CSV/изображения снаружи игры
в UBERTEST/runs. Прежние успешные выстрелы не являются приёмкой тактики.

Фактические проверки после исправлений:
- UBERTEST/policy_test.gd — PASS для пяти профилей, ограниченных попыток,
  запрета слепого огня и различий дистанции/наведения на синтетических данных.
- tests/ubertest_controls_regression.gd — PASS: загрузка всех пяти снимков,
  неизменность оригинальных CFG, окно/фон/возврат, пауза с замороженным временем,
  внешняя команда продолжения, сворачивание/восстановление, остановка в паузе.
- UBERTEST/ui_smoke.gd — PASS: реальные поля, переопределение выключено,
  отрисовка. Снимки просмотрены: runs/ui_check.png и
  runs/revision2-controls/window_check.png.
Перенос между физическими мониторами вручную, полный маршрут, бой и остальные
карты не проверены. Старые замеры 2× не выдаются за новый запуск этой версии.
