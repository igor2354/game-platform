# Единое отображение блокинга

**Правило пользователя и сверка кода: 2026-11-02.** На всех нынешних и будущих
картах диагностический блокинг отображается одинаково: тонкий бирюзовый контур
и полупрозрачная заливка поверх окружения. Текстуры и конструкция остаются
видны одновременно. Визуальное направление утверждено вторым пользовательским
снимком `Снимок экрана 2026-11-02 154247.png`, проектная копия `02_blocking_reference.png` в
`5_Проверки и отчёты/Полигон/core/casings_blocking_20261102/references/`.
Третий снимок с непрозрачным настилом — пример устраняемого расхождения.

Общая реализация — `scripts/core/blocking_overlay.gd`, подключение —
`CoreMovementLab._camera_settings_changed()`. F1 и независимый переключатель
F2 → камера/визуал → «Блокинг поверх окружения» используют этот же слой.
Включён любой из двух источников — блокинг виден; выключение F1 не отключает
независимую настройку. F1 сохраняет отдельные диагностики героя/врагов.

Заливка исходно0,18, регулируется существующим общим ползунком, значение
сохраняется в профиле камеры. Не задавать непрозрачный стиль отдельно карте.
Односторонние платформы и зоны лестниц — жёлтые; зона лестницы не стена.
Рисуются реальные активные неподвижные коллизии, включая обновления разрушений.
Отключённые оригиналы не рисуются. Линия у уточнённой геометрии Терры0,35 ед.
вместо2, чтобы не закрывать мелкие отверстия. Динамические тела в этот слой
не входят; их отдельная диагностика не является блокингом локации.

Старые процедурные непрозрачные схемы не должны включаться поверх игрового
арта по F1. Чистый полигон/Терра без текстур сохраняет свой базовый блокинг:
это само окружение, а не дополнительный диагностический фильтр.
На новых картах применять общий сервис к активным коллизиям; при самостоятельном
контроллере подключать его явно, не копировать отрисовку под конкретный уровень.
Никаких изменений формы поверхностей, текстур, масштаба героя или камеры ради
унификации фильтра не требуется.

Проверка: `tests/casings_blocking_smoke.gd` — оба пролога, хаб, полигон, Терра;
переключение F1/F2 и отсутствие старой непрозрачной схемы. Дополнительно
`tests/terra_blocking_overlay_smoke.gd` проверяет обновления после разрушений.
Снимки в `casings_blocking_20261102/` — результаты проверки, не новый арт-эталон.
