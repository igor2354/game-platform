# Контракт скелета гуманоида

Серый манекен `scenes/characters/humanoid_greybox.tscn` — эталон для всех гуманоидов: игрока, солдат и зомби на человеческой основе. Финальная графика встаёт на этот же скелет. Код и анимации при этом не меняются.

## Иерархия костей

```
Skeleton2D
└── pelvis                      таз, корень; стоит на высоте 105 над полом
    ├── torso                   торс, растёт вверх на 68
    │   ├── head                голова
    │   ├── arm_upper_l → arm_lower_l → hand_l    ближняя рука
    │   └── arm_upper_r → arm_lower_r → hand_r    дальняя рука
    ├── thigh_l → shin_l → foot_l                  ближняя нога
    └── thigh_r → shin_r → foot_r                  дальняя нога
```

- Персонаж смотрит вправо (+x). `_l` — ближняя к зрителю сторона, `_r` — дальняя. Разворот влево делается отражением всего скелета (`scale.x = -1`).
- Рост персонажа — 220 игровых единиц. Исходники рисуются в 2×.
- Изображение каждой кости — её дочерний узел `art`. Сейчас это серый `Polygon2D`, финальная графика — `Sprite2D` с тем же именем `art`. Файл называется по кости: `тип/thigh_l.png`.
- Точка вращения части — в суставе, то есть в начале кости. Конечности в покое висят вниз (+y), торс и голова направлены вверх, стопа — вперёд.
- Порядок отрисовки: дальняя рука (−2), дальняя нога (−1), торс и таз (0), ближняя нога (1), голова (2), ближняя рука (3).

## Знаки поворотов

| Движение | Знак |
|---|---|
| Рука или нога вперёд | минус |
| Сгиб колена | плюс |
| Сгиб локтя | минус |
| Наклон торса и головы вперёд | плюс |
| Носок стопы вниз | плюс |

## Анимации

| Имя | Длина | Цикл | Под какую скорость | События |
|---|---|---|---|---|
| idle | 2,0 с | да | — | — |
| walk | 1,0 с | да | 180 ед/с | `footstep` на 0 и 0,5 |
| run | 0,6 с | да | 420 ед/с | `footstep` на 0 и 0,3 |
| roll | 0,5 с | нет | — | `footstep` на 0,44 |
| climb | 1,0 с | да | 64 ед за цикл (две перекладины по 32) | `footstep` на 0 и 0,5 |

- Скорость проигрывания подстраивается под реальную скорость персонажа (`HumanoidRig.drive`). Если меняется длина шага, нужно поменять константы `WALK_SPEED`, `RUN_SPEED` и `CLIMB_CYCLE` в `scripts/characters/humanoid_rig.gd`.
- Перекат заканчивается поворотом таза на 360°. Поэтому переходы из него — без плавного смешивания.
- Каждая анимация задаёт ключи для всех костей, иначе при переключении останется поза из предыдущей.
- События кадров вызывают метод `emit_event("имя")` у корня. Имена событий берутся из общего контракта: `hit`, `footstep`, `mag_out`, `mag_in`, `bolt`, `throw`.

## Как проверить

Откройте `scenes/sandbox/rig_sandbox.tscn` и нажмите F6.

- A/D — шаг, Shift — бег, Пробел — перекат, W/S — лестница.
- 1–5 — одна анимация на месте, 0 — вернуться к управлению.

`tools/build_greybox_rig.gd` создаёт сцену манекена заново и затирает ручные правки. После первой правки в редакторе больше его не запускайте.
