# Пролог ver2: сверка пространственной логики

**2026-10-25. Godot 4.7.2 / Windows / GL Compatibility.** Выполнено поручение
привести ver2 к [правилам локаций](LOCATION_RULES.md). Проверялась только София
**1,00×**, STG-44, нынешний приземлённый профиль. Физический размер, анатомия,
анимации, параметры движения и камера этой работой не менялись. Исходный пролог
и полигон не переделывались. Это сухой блокинг, без новых текстур окружения.

## Согласованные здания

Пользователь выбрал **«Применить все три пункта»** после списка и снимков
[до/кандидат](../../../../2_Локации/Проектирование/mvp_village/Проверки/prologue_v2_logic_review_2026-10-25/review.md).
Размеры построек целиком не масштабировались.

- **Дом:** сплошная левая стена верхнего этажа; справа запланированное окно
  на существующий балкон: чистый просвет 2,20 м, подоконник 0,35 м.
  Полы 0,60/3,80 м, крыша 6,50 м; чистые высоты 3,00/2,70 м сохранены.
  Нижние дверные проёмы 2,30 м, внутренний лестничный люк сохранены.
  Выход из окна на балкон проверен спринтом с прыжком; обратный прыжок
  с балкона в окно не подтверждён и не требуется для выхода: есть лестница вниз.
- **Башня:** кабина на отметке 9 м закрыта по бокам, чистая высота 2,40 м;
  вход и выход через лестничный люк. Нижние уровни — открытый каркас.
- **Повреждённый вагон:** остатки обоих торцов ограничивают намеренные
  проломы с просветом 2,05 м и порогом 0,15 м. Добавлены сходни, соединённые
  с порогами. Проход проверен в обоих направлениях.
- **Бункер:** подвал уже ограничен настоящим грунтом, лишние стены не добавлялись.
  Проверены границы подвала, выходы через люки и подъём на крышу.

Окно и проломы пока открыты: механика стекла, дверей или разрушения этой
задачей не добавлена. Условный разрез для камеры не отменяет боковых стен.

## Локальные исправления маршрута

Сохранены **12 узлов / 484 м**, смертельный обрыв и исходная последовательность
ярусов. Исходный V4 и его данные не переписаны: уточнения реализованы локально
в `scripts/campaign/forest_prologue_v2.gd`. Исходное соотношение 17 плавных /
12 ступенчатых связок не пересчитывалось как новое художественное утверждение.

- Два безопасных приямка получили выходы по лестницам: у корней x=82,85 м
  и рабочей площадки x=177,85 м. Всего теперь **19 лестниц**, ширина 51,3 ед.
- J07: плоская вершина рабочего барьера расширена 0,70 →1,20 м для устойчивой
  опоры капсулы шириной ≈0,79 м; высота 0,90 м сохранена, сход перенесён к краю.
- J12: перед укрытием высотой 1,40 м добавлен подходной камень высотой 0,55 м
  и длиной 1,40 м. Проход использует существующий автопаркур спринта.
- J18: исправлен сценарий проверки — сначала устойчивый выход с лестницы,
  затем разбег; изменять способности героя для этого перехода не потребовалось.
- Проход под скалой x≈416–419 м имеет просвет ≈1,74 м: проходим в приседе,
  отмечен C. Капсула стоя ≈1,806 м, в приседе ≈1,242 м.
- Добавлены пояснения входов/выходов, окно → балкон, открытые опоры настила,
  подпись прыжка через смертельный обрыв Shift+Space.
