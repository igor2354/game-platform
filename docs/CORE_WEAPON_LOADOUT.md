**Общий контракт нативного 3D:** [CORE_3D.md](CORE_3D.md).

13.11.2026. Явное поручение пользователя: выбранное оружие + обязательный
пистолет, переключение цифрами. Текущий secondary_id=m1911; параметр
configure позволяет заменить его будущим пистолетом без изменения слотов.

1 / Num1 — выбранное основное; 2 / Num2 — пистолет. Если в меню выбран
сам 1911, оба номера указывают на один экземпляр, без дублирования патронов.
weapon_loadout.gd общий для нативного combat и 2D-контроллера кампании.
Патроны магазина/резерва, cooldown и балансируемые значения каталога
сохраняются отдельно по оружию. Переключение не пополняет патроны, отменяет
reload штатным cancel_reload и блокируется паузой/интерфейсом/смертью.
Ввод числа в LineEdit/TextEdit не переключает оружие.
3D equip получил preserve_projectiles: уже летящие пули продолжают путь
с записанными скоростью/уроном/id, а не исчезают при смене слота.
Слоты живут в пределах игровой сессии: сохранение инвентаря между запусками
или картами этим поручением не реализовано. Неактивная модель скрыта,
AnimationPlayer пистолета отключён вместе с её processing. Не добавлены
визуальные кобура/ремень/вынимание оружия.

Выбрана вторая: меньше геометрии и объём ресурсов, есть Fire. Это сравнение
сложности ресурсов, не FPS-бенчмарк. Исходники сохранены снаружи; подключена
resources/core/weapons_3d/M1911.glb и три импортированных текстуры,
внесены в runtime_media.json. Размер вдоль ствола 0.218 м, равномерный
масштаб 0.218/46.17282, разворот Y=PI. Рукоять/поддержка/дуло собственные.
Fire запускается только от настоящего shot_fired, не из render tick;
loop выключен, пауза останавливает проигрывание. Модель использует общий
mount, отдельную пистолетную постановку без упора приклада в плечо.
Магазин в исходнике не выделен отдельной сеткой: прежний proxy-drop
сохраняется на reload, лишний висящий proxy в обычной стойке скрыт.
Новая разметка skin для отделения реального магазина не выполнялась.
Общие визуальные дефекты пальцев/ADS остаются открытыми.

## Пауза, размер, цикл и хват — исправление 13.11

Курсор: исправлен неверный уровень отступа MOUSE_MODE_CAPTURED, который
оказался вне if wanted. Пауза теперь показывает системный указатель,
продолжение возвращает захват; пистолетный AnimationPlayer.active следует
паузе, а не сбрасывает рассчитанную скорость клипа каждый render frame.

Прежнее 0.218/46.17282 было ошибкой: get_aabb вернул bind-геометрию,
а реальная сетка после skinning в нулевой позе Fire имеет длину 23.95461.
Аудит суммирует bone_global_pose*bind_pose*vertex по четырём весам.
Масштаб исправлен на 0.218/23.95461: видимый пистолет вырос примерно 1.93×,
пропорции не менялись. Точка модели сдвинута X=.045, дуло (.155,.045,0).

Fire исходно 6.6667 с. Каждый show_shot делает stop → play → advance(0);
скорость clip.length/min(0.12,0.8*60/RPM). По умолчанию цикл 0.12 с,
при повышении RPM сокращается, чтобы не перекрывать следующий выстрел.
Звук/пуля не запускаются анимацией повторно.

ADS: цели обеих ладоней сближены на рукояти, с опорой второй руки
на противоположной стороне; убран винтовочный минимум front_grip.x=.06.
Цель оружия выносится дальше вперёд, локти сохраняют мягкий сгиб.
