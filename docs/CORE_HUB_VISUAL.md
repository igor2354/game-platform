# Хаб: подключение 8K по блокингу07 — 2026-11-01

Поручение пользователя: наложить текстуры по чертежу/блокингу, использовать
изображение хаба8K. Источник в медиатеке:
`2_Локации/Концепты локаций/ХАБ/Кандидаты/ХАБ_Мрачные_2D_2026-10-31/Железнодорожное убежище — реконструкция 8K.png`.
Фактический размер **7680×2560**, совпадает с исходником чертежа07.
Это явное разрешение использовать этот источник в игре, не утверждение
всех прочих кандидатов хаба и не новая география.

## Реализация

`hub_visual.gd` подключён только в `hub_level.gd`. Восемь PNG — точные
фрагменты исходника, без ресайза, с двухпиксельным запасом для фильтрации.
Все восемь явно подключены и включены в `tools/runtime_media.json`.
Максимальный размер отдельной текстуры964×2560, исходная детализация сохранена.
`tools/prepare_hub_texture.gd` сначала готовит внешние копии, затем устанавливает
только производные, присутствующие в разрешённом runtime-списке.

Привязка по корпусам X0/24/28/48/68/72/80 м и уровням0/4,4/7,8/11,2/14,6 м.
Левая/правая башни учитывают свои крыши14,25/17,65 м. Рисунок пола не является
новой коллизией: настилы рисуются по фактическим `floor_rects` с сохранением
лестничных проёмов. В административном корпусе добавлены внутренние якоря
для дверей/мебели; дополнительная высота приходится преимущественно на стены.
Нижние проходы башен2,2 м показаны открытыми, вместо прохода сквозь каменный
столб рисунка. Стены, этажи, вход, маршруты, камера и размер Софии не изменены.

Исходные нарисованные лестницы не совпадают с четырнадцатью игровыми маршрутами.
Их внутренняя область заменена каменным материалом из того же источника;
металлические косоуры, ступени и задние перила построены по `stair_flights`.
Это адаптация арта, не перемещение коллизий. Результат отличается от исходной
живописной клетки: повторяющаяся кладка и геометрические перила видимы.
Шаг ступеней ≈18 ед. по высоте; новые ступени остаются визуалом непрерывного
марша, отдельных физических ступенек не добавлено.

Весь арт позади акторов (`z_index=-10`). Никакого нового перекрытия персонажа
мебелью или перилами. Прежние подписи/заливки блокинга скрыты, общая диагностика
коллизий остаётся в прежнем инструменте. R/U/услуги не получили новых функций.

## Границы результата и проверки

Это первая игровая сборка утверждённого к использованию концепта. Исходник
плоский: мебель/лампы/комнаты остаются частью рисунка; нет новых предметов,
NPC, динамического освещения, отдельного интерьерного посещения или переднего
плана. Дальний план и небо взяты из того же рисунка, не являются независимыми
послойными художественными исходниками для параллакса/погоды. Это ограничение,
а не отмена [правил последующего производства слоёв](ENVIRONMENT_BACKGROUNDS.md).
Локальная регистрация может менять пропорции отдельных деталей; полное
метрическое и художественное утверждение каждого предмета не заявляется.
Успех теста стыков PNG сам по себе не доказывает отсутствие всех художественных
нестыковок. Не объявлять эту сборку новым окончательным эталоном.

Фактически: `hub_visual_smoke.gd` **19/19** (нативные размеры8 фрагментов,
побайтовое совпадение7 перекрытий, порядок слоёв, размер Софии, 14 маршрутов),
`hub_blocking_smoke.gd` **26/26**, `ordinary_stairs_smoke.gd` **96/96**.
В проверках все пять CFG перенаправлены во временные каталоги.
Оконные кадры2560×1440: вход, лестницы, госпиталь, кухня, общий вид просмотрены;
в съёмке туман выключен для проверки арта, обзорный zoom диагностический,
настройки игры не сохранены. В итоговом журнале нет SCRIPT ERROR/ERROR.
Первая попытка содержала неверный порядок аргументов отрисовки; исправлено
до итогового запуска. Проверка медиа: **118 файлов /254 пути /0 ошибок**.
Это не проверка всего проекта, экспорта или производительности GPU.
