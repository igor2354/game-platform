# Паркур: захват уступа и преодоление препятствий

## Исправление ручного захвата — 2026-10-26

По сообщению пользователя о незахватываемых уступах ver2 воспроизведены
отказы на настоящем стволе, переднем уступе корневой ямы и укрытии. Причина
подтверждена: тело имело высоту 182,4 ед., а ручная досягаемость оставалась
76 ед. (≈0,75 м) от прежней капсулы 64 ед. Это был дефект расчёта, а не только
старого теста. Автоматический режим уже учитывал размер.

Ручные расстояния переведены в мировые единицы базовой Софии 1,00×, затем
умножаются на `motion_scale()`, как остальные размеры движения.

| Параметр | При Софии 1,00× |
|---|---:|
| Захват от края тела | 34,2 ед. ≈0,34 м |
| Максимальная высота уступа над стопами | 216,6 ед. ≈2,15 м |
| Предел низкого препятствия | 136,8 ед. ≈1,35 м |
| Предел ширины насквозь | 273,6 ед. ≈2,71 м |
| Зазор над опорой | 11,4 ед. ≈0,11 м |
| Допустимый спуск за препятствием | 91,2 ед. ≈0,90 м |

Физические размеры автопаркура, длительности, прыжок/гравитация, камера,
геометрия уровня, внешность и анимации этим исправлением не менялись.
Непроходимый потолок по-прежнему запрещает захват. Малая опора, дальний уступ
или закрытая кабина не становятся допустимыми из-за большего радиуса поиска.

В CFG/JSON добавлен служебный `parkour_basis_version=2`, независимый от
`scale_basis_version=2`. Если поля нет (версия 1), только шесть перечисленных
расстояний при загрузке умножаются на 2,85; пользовательские отношения
сохраняются. Текущая версия не переводится повторно. Неизвестная версия
отклоняется до изменения настроек. Старые реальные CFG сами не перезаписаны.
F2 → Игрок → Движение → Паркур показывает базовые единицы и реальные метры,
а при другом размере — соответствующие производные значения.

Новый `prologue_v2_manual_parkour_smoke.gd` — **29/29**: шесть настоящих
уступов ver2, потолок кабины, София 1,20×, метрика, старые/новые CFG и JSON,
идемпотентность и отказ неизвестной версии. До исправления три проверяемых
реальных захвата не срабатывали. Сняты 12 кадров хвата/завершения с блокингом.
Прежний `parkour_smoke.gd -- --sofia-only` — **71/71**: его искусственный
стенд использует капсулу 64 ед. по размерам фикстур, а реальный ствол старого
пролога проверяется игровой Софией. Этот стенд не подменяет новые проверки
настоящей Софии 1,00× в ver2. Фиксация рук на уступе всё ещё не анимирована;
на кадрах используется существующая поза прыжка, она не объявлена утверждённой.

целевых наборах: реальные ручные захваты ver2 29, прежний стенд 71,
автопаркур 79, нормализация 36, потолки 71, меню 99, здания 42, полный
непрерывный маршрут ver2 46. Ошибка разбора намеренно повреждённого
временного CFG в наборе меню ожидаема. Гарри не запускался. Пять реальных
CFG до/после совпали по SHA256; все сохраняющие тесты используют пять
временных путей. Runtime-медиа: 95 файлов /245,96 MiB /206 путей /0 ошибок.
[Кадры и журналы](../../../../2_Локации/Проектирование/mvp_village/Проверки/manual_parkour_2026-10-26/README.md).
Это целевая сверка затронутых систем, не художественная приёмка и не тест
всей игры. Новый EXE не экспортировался.

**Новая база 2026-10-25:** та же София теперь 1,00× (прежние 2,85×).
Ширина автопаркура теперь в мировых единицах: 273,6 ед. при 1,00×;
фактические ширины, высоты и длительности сохранены. Ручные времена
профиля пересчитаны к новой базе. [Полный перенос данных](SCALE_NORMALIZATION.md).

## Автоматическое преодоление в спринте — 2026-10-25

По новому поручению **Shift + A/D** автоматически запускают преодоление
неподвижной геометрии высотой от колена до груди, **без пробела**. Реализация
общая для полигона/кампании; проверена только София. Обычный бег и Ctrl-ходьба
не включают автоматический захват. Ручной паркур ниже сохранён.

По умолчанию диапазон — **0,25–0,75 стоячей высоты капсулы**. При Софии
2,85× это **45,6–136,8 ед.**; границы автоматически следуют размеру героя.
Направление задаёт движение спринта, включая курсор с другой стороны.
Узкое препятствие преодолевается насквозь на проверенную опору; на широкий
уступ герой поднимается сразу, без ожидания второго нажатия. Проверяются
полный стоячий габарит, потолок, опора и весь путь; коллизии не отключаются.
Динамические предметы по-прежнему не считаются опорами паркура.

Автоматический поиск выполняется с земли, при доступном спринте, без
перезарядки, ADS, стрельбы, приседа, захвата предмета, гранаты, дэша и подката.
При невозможном маршруте действие не начинается. Максимальная ширина для
перехода насквозь — `sprint_auto_max_width × motion_scale()`; расстояние поиска,
зазор и предел спуска используют параметры в мировых единицах Софии 1,00×,
умноженные на `motion_scale()`. С 26.10 ту же размерную опору использует
ручной режим; его пределы перечислены выше.

**F2 → Игрок → Движение → Паркур**: отдельный переключатель
`sprint_auto_parkour_enabled` и четыре параметра:

| Ключ | По умолчанию |
|---|---:|
| `sprint_auto_min_height_ratio` | 0,25 роста |
| `sprint_auto_max_height_ratio` | 0,75 роста |
| `sprint_auto_max_width` | 273,6 ед. при 1× |
| `sprint_auto_vault_time` | 0,32 с, без деления на размер |

Настройки входят в прежние CFG/JSON, старые профили получают значения по
умолчанию. Выключение автоматики не стирает параметры и прерывает активное
автопреодоление; ручной паркур остаётся доступен при включённом общем паркуре.
Запас спринта расходуется и во время действия. После завершения сохраняется
входящая горизонтальная скорость, если игрок продолжает спринт в ту же сторону
и запас не исчерпан. Пауза останавливает действие, C отменяет его.

Новые рисунки/анимации, изменение пропорций, длин рук и камеры не добавлены:
используются существующие состояния `vault`/`mantle` и имеющаяся поза прыжка.
Это функциональная реализация, художественная приёмка движения не выполнена.

Свежие проверки Windows / Godot 4.7.2: `sprint_auto_parkour_smoke.gd`
**75/75** (оба направления, колено/середина/грудь, 1/2,85/3,5×, широкая
опора, потолок и запреты, расход спринта, C, пауза, выключение, CFG/JSON,

## Управление и выбор действия

Удерживать **Пробел** возле края, глядя лицом к нему. Захват ищется по стороне
взгляда оружия, а не направлению A/D: движение спиной к препятствию не запускает
паркур. На свободном месте остаётся обычный прыжок; удержание в воздухе позволяет
поймать досягаемый уступ.

**Два этапа для уступа:** удержание запускает хват (`ledge_hang`), после чего
персонаж остаётся висеть без ограничения времени. Нужно отпустить Пробел и
нажать его снова, чтобы начать подъём (`mantle`). Первое удержание и само
отпускание не запускают подъём. После начала подъёма удерживать Пробел не нужно.

Новое нажатие **C** прерывает висение, подъём или преодоление низкого блока.
Отпускание Пробела ничего из этого не прерывает. Если при отмене Пробел оставался
зажатым, повторный хват разрешается после его отпускания и нового удержания,
чтобы персонаж сразу не цеплялся обратно. Другие системные прерывания сохранены.

- Невысокое узкое препятствие: подняться выше верхней грани, перейти на другую
  сторону, опуститься на проверенную площадку. По умолчанию высота до **48 px**,
  ширина до **96 px**. При высоте капсулы 64 px это примерно уровень груди.
- Более высокий или широкий блок: захват и ожидание повторного нажатия,
  затем подъём и выход на его верх.
  Досягаемость верхней грани — до **76 px** над текущими стопами; высокий
  объект можно поймать в прыжке. Воздушный захват ищет край от 40 px над стопами.
- Если за низким блоком нет безопасного приземления, выбирается подъём на верх.
  Если сверху или на пути нет места для полного тела, действие не начинается.

Низкий узкий блок преодолевается сразу по первоначальному удержанию Пробела
без отдельного висения и второго нажатия. После запуска движение завершается
самостоятельно, если игрок не отменил его C или не возникло препятствие.

Проверяются вертикальная грань, достаточно ровный верх, опора с двух сторон
капсулы, свободный объём и весь маршрут полным стоячим габаритом. Коллизии не
отключаются; каждый шаг движения также проверяет столкновение. Новый предмет
на пути прерывает движение. Ноги/корпус не уменьшаются для прохождения.

Сейчас опоры — неподвижная геометрия `StaticBody2D` слоёв 1/8, включая края
односторонних платформ. Динамические ящики, бочки, враги и движущиеся платформы
не служат захватами. Преодоление больших провалов и лазание вдоль края не добавлены.

## Состояния и совместимость

`scripts/core/parkour.gd` хранит `ledge_hang`, `mantle`, `vault`, направление,
край, конечную точку и прогресс. Пока `hybrid_body.gd` показывает существующую
фиксированную позу прыжка; привязки рук к уступу, новой рисованной анимации,
скрывания оружия и художественной приёмки паркура ещё нет. Эти состояния
предназначены для последующего подключения анимации.

Во время действия блокируются стрельба, прицел, перезарядка, гранаты, дэш,
подкат и захват предметов. Толчок, рэгдолл, смерть, исчезновение опоры,
выключение механики, F8 и переход очищают состояние. Пауза останавливает
таймер; блокировка игрового ввода панелью удерживает текущую точку.
Сохранение профиля не сохраняет живое состояние паркура.

Реализация общая для полигона и кампании, Софии и Гарри. Высокий старый блок
полигона (x=640, высота 70) сохранён. Рядом добавлен низкий **56×48 px**
(x=800) и подсказка удержания пробела. В прологе проверен захват существующего
ствола после прыжка; его геометрия не менялась.

## Настройки разработчика

Таблица ниже — исторические значения 23.10 для капсулы 64 ед.; текущая
мировая база и перенос профилей описаны в разделе исправления 26.10 выше.

**F3 → Паркур**: независимый переключатель и десять параметров с ползунком
и числовым вводом. Выключение освобождает захват, сохраняя значения.
Переключатель обычного прыжка независим: он запрещает импульс отталкивания,
а не захват уже доступного уступа.

| Ключ | По умолчанию |
|---|---:|
| `parkour_reach` — расстояние от края капсулы | 12 px |
| `parkour_ledge_height` — досягаемость над стопами | 76 px |
| `parkour_vault_height` — низкое препятствие | 48 px |
| `parkour_vault_width` — ширина для перехода насквозь | 96 px |
| `parkour_clearance` — зазор над препятствием | 4 px |
| `parkour_hang_time` — минимальное время фиксации хвата | 0,14 с |
| `parkour_mantle_time` — подъём и выход | 0,65 с |
| `parkour_vault_time` — преодоление низкого блока | 0,55 с |
| `parkour_regrab_delay` — повторный захват | 0,25 с |
| `parkour_drop_limit` — спуск за низким блоком от исходных стоп | 32 px |

Тайминги фиксируются в начале действия, остальные новые попытки используют
текущие значения. Все 11 ключей входят в прежний movement CFG и JSON версии 1.
`parkour_hang_time` не ограничивает длительность висения и не включает
автоматический подъём. Быстрое повторное нажатие принимается в пределах
этого времени, но движение начнётся после его окончания. Ключ сохранён для
совместимости существующих профилей.
Старые файлы получают включённый паркур с базовыми параметрами.
Поиск выполняется только при удержании прыжка в допустимом состоянии;
число лучей ограничено диапазонами настроек, обхода всех объектов сцены нет.
