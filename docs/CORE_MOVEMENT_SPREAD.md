# Разброс при движении

**F4 → «Разброс в движении»** (в режиме разработчика: «Игрок → Стрельба и урон»)
содержит отдельный переключатель и семь ползунков с точным числовым вводом.

| Настройка | По умолчанию | Диапазон |
|---|---:|---:|
| При движении вперёд · добавка ± | 3° | 0–35° |
| При движении назад · добавка ± | 6° | 0–35° |
| Скорость начала штрафа | 10 px/с | 0–1000 px/с |
| Скорость полного штрафа | 320 px/с | 10–2000 px/с |
| Плавность нарастания | 0,15 с | 0–2 с |
| Плавность восстановления | 0,30 с | 0–3 с |
| Штраф в прицеле | 0× | 0–2× |

«Вперёд» и «назад» определяются относительно направления взгляда,
по фактической скорости персонажа. Нажатие противоположной клавиши
не меняет штраф, пока герой ещё движется по инерции в прежнюю сторону.
Вертикальное прицеливание использует сохранённую сторону взгляда.

До начальной скорости добавки нет. Между двумя порогами штраф линейно
растёт до выбранных градусов; выше второго порога не увеличивается.
На склоне учитывается скорость вдоль поверхности, а не только горизонтальная
составляющая. Замедление задом, стрельбой, ходьбой и приседанием уже входит
в реальную скорость: более медленное движение даёт меньший штраф.
Упор в стену не считается бегом. Порог полного штрафа всегда выше начального.

От бедра итог равен **базовому разбросу + накоплению очереди + добавке движения**.
Ограничение «Максимальный разброс» во вкладке «От бедра» относится к первым
двум слагаемым: добавка движения может увеличить общий угол выше него.
Одинаково работает при одиночной и автоматической стрельбе.
Общий угол показывает прицел и телеметрия.

В прицеле по умолчанию добавки **нет**: сохраняются точные выстрелы
в покачивающуюся точку. Коэффициент выше нуля разрешает случайный разброс
при движении с ПКМ; его величина равна добавке движения, умноженной
на коэффициент. Дополнительное кольцо прицела показывает этот угол.
На месте после восстановления прицел снова точный.

Плавность задаёт постепенное приближение к новому штрафу: чем больше
время, тем медленнее изменение; 0 означает мгновенную реакцию.
Это сглаживание, а не задержка перед включением. При остановке,
прыжке, дэше, подкате или захвате лестницы уже накопленная добавка
плавно убывает; новый наземный штраф в этих специальных состояниях не растёт.
Пауза останавливает сглаживание. F8 очищает накопленную добавку.

Переключатель снимает только штраф движения сразу, сохраняя значения
ползунков, стрельбу, базовый разброс и накопление очереди.
Настройки сохраняются в `user://core_shooting.cfg` и общем JSON версии 1.
Старые профили получают значения из таблицы.

`tests/movement_spread_smoke.gd`: **54 проверки** настоящего бега в обе стороны
относительно обоих направлений взгляда, одиночных/автоматических пуль,
суммирования с очередью, порогов скорости, смены направления по инерции,
нарастания/восстановления, прицела с нулевым/ненулевым коэффициентом,
стены, прыжка, паузы, переключателя, всех контролов, CFG и старых/новых JSON.

Снимки создаёт `tools/capture_movement_spread.gd`.
