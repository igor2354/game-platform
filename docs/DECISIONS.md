# Память проекта: принятые решения и планы

Сверка с перепиской и активным кодом: **2026-10-17**.
Фактическая карта систем — [PROJECT_STATE.md](PROJECT_STATE.md).
Новые указания пользователя заменяют прежние договорённости. Не возвращать
старое поведение только потому, что оно встречается раньше в истории чата.

## Принятые решения, реализованные в прототипе

| Область | Договорённость, которую нужно сохранять |
|---|---|
| Направление разработки | Сохранить прежние художественные наработки, проектировать основные механики на полигоне с упрощёнными моделями. Активный вход — `scenes/main.tscn`. |
| Движение и клавиши | A/D — обычный бег без отдельного модификатора. Ctrl — отдельная медленная ходьба стоя; Shift — ограниченный по времени спринт; Alt — дэш; C — присед и подкат из спринта. Прежнее название обычного бега «ходьба» не возвращать. |
| Направление тела | Обычный бег, Ctrl-ходьба и присед могут идти задом относительно прицела. Спринт разворачивает модель по движению. Дэш из спринта и подкат сохраняют направление своего движения; курсор с другой стороны не должен выворачивать часть модели. |
| Скорость | Отдельные коэффициенты заднего хода, подъём медленнее/спуск быстрее, отдельные коэффициенты дэша на склонах. Замедление стрельбы применяется вместе с движением. Плавность разгона регулируется отдельно от величины ускорения. |
| Прыжок и дэш | Темп движения влияет на горизонтальную длину прыжка. Дэш проходит сквозь врагов, но не через окружение. Дэш в прыжке/падении можно отключить; уже начатый дэш завершается штатно. Текущий дэш также защищает от урона и физического сбивания взрывом. |
| Подкат | Активировать новым нажатием C во время спринта. Контакт наносит урон; сбивание имеет отдельный тумблер, шанс, скорость, отбрасывание и отдельное время на земле у людей/зомби. Зомби по умолчанию встаёт дольше. |
| Анимация игрока | Гибрид запечённого тела и сегментных рук; циклы по 8 кадров. При прицеливании оружие на уровне плеча, голова наклоняется к прикладу. Это заменило раннее пожелание просто поднять оружие на уровень глаз. |
| Зомби по концепту | По указанию пользователя от 2026-10-16 образ в оливковой форме с красными погонами, наградами и короткими волосами внедрён как отдельный зомби-солдат Z02. Все 22 клипа имеют по 16 кадров, детали сохраняются при отрыве конечностей и в физике. Прежний зомби остаётся отдельным; новая область слева доступна по F10, F9 сохраняет прежний смысл. Использовать общий ИИ/баланс, не заводить вторую расходящуюся копию поведения. Уточнение 2026-10-17: локти и колени не выворачиваются в анимациях и подъёме, длина сегментов постоянна; голова соединена с воротником общей точкой шеи, включая физическое падение. Руки крепятся к боковым плечевым точкам ниже воротника и следуют повороту торса во всех позах, а не растут от шеи. [Описание](CORE_CONCEPT_ZOMBIE.md). |
| Перезарядка | Две руки без визуальной «третьей». Оружие приподнимается стволом вверх. Порядок спереди назад: передняя рука → автомат → магазин → задняя рука; доставаемый магазин также скрывается за телом. Слои реализованы в визуальных слоях игрока и раздельной отрисовке магазина/оружия/рук. |
| Стрельба | От бедра есть нарастающий разброс и среднее замедление; ADS на ПКМ даёт точную базовую линию с покачиванием и сильным замедлением. Автоматический и одиночный режимы; магазин конечный, R — перезарядка. Отдельно регулируется дополнительный разброс при беге вперёд/назад и его влияние на ADS. |
| Отдача | Включена по умолчанию. Курсор и перекрестие — одна игровая точка, отдача меняет её и линию огня, а не только трясёт камеру. Относительный ввод позволяет длительно компенсировать отдачу. Нужны отдельные настройки от бедра/ADS, непрерывный режим и точные числа. |
| Автокомпенсация | Возвращает только некомпенсированный остаток отдачи; учитывает ручное движение и уступает при перенаведении. Не должна повторно уводить прицел вниз после ручной компенсации и не является наводкой на противника. Есть выключатель и интенсивность. |
| Курсор и камера | Курсор скрыт в обычном геймплее с возможностью показать. Камера плавно меняет сторону; возле прицеливания строго вверх/вниз сохраняется выбранная сторона в пределах регулируемого допуска (базово 35°). Смещение камеры и тряска не считаются движением мыши. |
| Звук | Отдельные акценты попадания и убийства. При низком остатке магазина меняется тон выстрелов, последняя пуля имеет отдельный акцент. Порог и тональность настраиваются. |
| Конечности | Отстрел головы/туловища/рук/ног обрабатывается раздельно. Потеря рук/ног не обязана убивать. Потеря любой ноги сразу валит зомби; потерянные части не восстанавливаются до возрождения. |
| Ползущий зомби | Не патрулирует лёжа и не ползёт домой просто по расписанию. Двигается при наличии обнаруженной цели, шума/реакции на попадание и соответствующей памяти. Это не вечное знание игрока сквозь стены. |
| Чувства зомби | Зрение — конус по взгляду, ориентируется по наклону поверхности; слух — 360°. Попадание со спины вызывает реакцию даже без слуха. Близкий контакт с игроком, поиск у достигнутого источника шума и память цели не должны застревать из-за старой позиции шума после дэша. |
| Пропасти | Преследуя цель или исследуя шум, зомби идёт через край и падает, продолжая поиск после приземления. Отсутствие самосохранения относится к погоне; не требуется превращать патруль в намеренное падение. |
| Ошеломление | Дэш сквозь зомби даёт окно для контратаки/отхода/перезарядки: враг останавливается, прерывает атаку и не поворачивается. Повторное наложение обновляет таймер без суммирования; контакт не отменяет эффект. После окончания возобновляется обнаружение/бой, включая контакт с присевшим игроком за спиной. Общий метод пригоден для будущих гаджетов. |
| Ящик и предметы | Для перемещения игрок должен явно захватить предмет через G; повторное G отпускает. Упор без захвата не даёт толкания. Обе руки держат предмет, оружие переносится за спину. Свободная физика от гравитации, выстрелов и взрывов сохраняется. |
| Разрушение ящика | Собственные HP, разрушение от стрельбы, мелкие физические обломки без автоматического исчезновения. Они легко раздвигаются игроком и не мешают проходу. Очистка при явном восстановлении полигона допустима. |
| Бочки | Взрывная и топливная — разные типы. Общая модель, различие цветом/содержимым; ещё пустая и негорючая. Все физические. Топливо даёт постоянные следы/лужи, огонь распространяется по разливу. G сначала укладывает бочку от героя, затем позволяет катить. |
| Подвесы | Один груз — деревянный ящик, другой — настоящая физическая сетка с отдельным содержимым. Выстрел в трос/крепление вызывает падение. Урон зависит от массы/скорости, габаритов и содержимого. Сетка должна деформироваться уже на подвесе, рваться физически и успокаиваться в покое. |
| Граната | T достаёт гранату с динамической дугой, повторное T убирает только до запала. Таймер начинается **с нажатия ЛКМ**, а не с T. Удержание увеличивает силу, отпускание бросает; запал не перезапускается, граната может взорваться в руках. Отскок и прямой физический урон регулируются. |
| Радиусы взрыва | Основной радиус может убивать; внешняя волна сохраняет минимум 1 HP. Укрытие блокирует урон/импульс. Взрыв повышает шанс отрыва конечностей. Герой и зомби при физическом падении сохраняют свою модель; рэгдолл не должен выглядеть тестовым манекеном. |
| Ближний взрыв | При включённом рэгдолле игрок падает и в основном радиусе, вплоть до эпицентра. Минимальная дистанция ограничивает для него только внешнюю волну; у врагов её прежний смысл сохранён. Бессмертие сохраняет HP, но не запрещает физическое падение. |
| Режим разработчика | Единое окно F2. Категория «Игрок» содержит движение, стрельбу/урон, камеру/визуал и отдельное здоровье. Каждая механика имеет собственный тумблер; выключение не стирает баланс. «Дэш на склонах» включён в «Дэш», сбивание — в «Подкат». |
| Тестирование | F1-отладка и обычная телеметрия остаются после закрытия F2. F7 возрождает врагов, F8 восстанавливает полигон. Есть управление HP/бессмертием героя и врагов, остановка всех врагов без остановки игрока. Снимок взрыва на F1 остаётся до следующего взрыва/F8. |
| Совместимость | Переносы страниц не меняют ключи сохранений: здоровье остаётся в секции движения, физика/гранаты — в `ragdoll`. Старые JSON/CFG должны загружаться с базовыми значениями отсутствующих новых полей. |
| Экран | 16:9 и полноэкранный запуск; F11 переключает окно/полный экран. |

## Обсуждавшиеся планы: реализация не подтверждена

Пользователь перечислил следующие направления. Они сохранены для
проектирования, но не образуют утверждённое техническое задание на все системы.

| Направление | Пожелание и граница текущей реализации |
|---|---|
| Характеристики выживания | Здоровье, запас выносливости на дэши и скорость её восстановления, скорость бега. Сейчас есть HP, скорости, восстановление дэша и временной запас спринта; общей расходуемой выносливости на дэши нет. Формулировку «при дэш перекат недоступен» нужно уточнить при проектировании — отдельный перекат ещё не реализован. |
| Параметры боя | Меткость как общий множитель разброса, контроль отдачи как множитель ствола/камеры, скорость перезарядки как множитель, число запасных магазинов на вылазку, время смены оружия и перехода в точный прицел. Сейчас есть локальные настройки оружия/разброса/отдачи/времени перезарядки, переход ADS и запас патронов; общей системы характеристик персонажа и экипировки нет. |
| Полевая медицина | Сила лечения аптечкой и длительность применения. Полное лечение в меню разработчика не является механикой аптечки. |
| Различия персонажей | Пол, класс, редкость (обычные/редкие), внешность, БИО, уникальные сюжетные квесты и боевые анимации. |
| Способности | Уникальные способности, бафы/дебафы, рандомизация персонажа/способности, персонажи-оболочки с уникальной способностью и внешностью. Есть технический эффект ошеломления, но не общая система всех эффектов/способностей. |
| Смерть и спасение | Механика смерти и спасения своего персонажа. Текущие HP, физическое тело и тестовое возрождение не заменяют полноценную систему спасения/последствий смерти. |
| Отношения и сюжет | Отношения с «рехабовцами», сюжетные квесты и персональные истории. |
| Напарник | Помощь в бою и соответствующее поведение ИИ. |
| Дальнейшая физика | Обсуждались гранаты, обломки/тела, подвесные объекты и разрушение. Эти конкретные прототипы уже есть; отдельные цепи/лампы, новые виды взрывчатки и окружения добавляются по будущим заданиям. |

## Как продолжать после перерыва

1. Прочитать состояние, выбранное решение и профильный документ.
2. Проверить текущую реализацию и реальные значения ресурса/профиля.
3. Внести запрошенное изменение, проверить затронутые сценарии.
4. Обновить эти файлы по существу; заменять устаревшую запись, не копить
   взаимоисключающие инструкции. Не добавлять догадки в список готовых механик.
