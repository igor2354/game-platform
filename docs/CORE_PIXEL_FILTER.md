# Пикселизация и фон для проб в прологе

Реализовано **2026-10-23** по прямому поручению пользователя.

**F5 → Визуал → «Пиксельный фильтр»** или
**F2 → Игрок → Камера и визуал → Визуал**.
Рядом находится синхронизированный выключатель нуара; отдельная вкладка
«Нуар» сохраняет его прежние подробные настройки.

Размер пикселя — ползунок и точный ввод **1–16 px экрана**, по умолчанию **3**.
Меньше размер — больше исходных деталей; **1** возвращает исходную детализацию.
Фильтр выключен по умолчанию. Выключение сохраняет размер. «Сохранить»
или «Сохранить всё» записывает `pixel_enabled` и `pixel_size` в прежний
профиль камеры и общий JSON версии 1. Старые профили оставляют фильтр выключенным.
Работает сразу, в том числе на паузе, в прологе и на полигоне.

## Обработка

Пикселизация использует один цвет из центра каждого квадратного блока экрана.
Она включена в тот же [шейдер](../shaders/core_noir.gdshader) и
[экранный слой](../scripts/core/noir_filter.gd), что и нуар: сначала выборка
по пиксельной сетке, затем чёрно-белая обработка и красные акценты.
Оба выключателя независимы: нулевая сила нуара не отключает пикселизацию.
Если оба эффекта неактивны, копирование и обработка экрана выключены.
HUD, меню и прицел остаются чёткими и сохраняют цвет.

Это имитация пикселизации, без ограничения палитры и дизеринга. Она не добавляет
отсутствующие детали лица и не заменяет ручную работу над пиксель-артом.
Сетка привязана к экрану: при движении камеры содержимое блоков меняется;
это не квантование перемещения камеры и не отрисовка игры в низком разрешении.
Размер относится к пикселям отрисовки: на другом разрешении доля экрана меняется.

## Лесной фон

Пользователь явно разрешил подключить «Лес перед осадой — 4K.png»
**3840×2160** в пролог для проверки фильтров. Оригинал скопирован без
перерисовки и искажений в [общую библиотеку](../../../../2_Локации/Проектирование/mvp_village/Утверждено/Пролог_лес_2026-10-23/Лес%20перед%20осадой%20—%204K.png)
и в [игровой ресурс](../resources/campaign/prologue_forest_4k.png).
Копии совпадают с присланным файлом по SHA256. Ресурс внесён в `runtime_media.json`.
Разрешение использовать этот фон для проб не утверждает окончательный стиль игры.

В [forest_prologue.gd](../scripts/campaign/forest_prologue.gd) изображение —
Sprite2D в координатах мира, под героем, равномерный масштаб **0,625**.
Точка тропинки **(1440,1650)** в исходнике совмещена со стартовым полом
**(12400,760)**; верхний левый угол изображения **(11500,−271,25)**.
При движении камеры фон остаётся на месте. Камера и физика не менялись.

Фон предназначен для **начала пролога**, не растянут на все 330 высот героя.
На первом участке убраны непрозрачная заливка земли и сетка, оставлен тонкий
контур физической поверхности. Убрана повторная отрисовка лесной геометрии
родительским полигоном; коллайдеры, уклоны, лестницы и дальнейшие участки прежние.
Совмещение проверено у старта: перспективная тропинка изображения не повторяет
все последующие физические неровности. При сильном отдалении камеры или выходе
за пределы иллюстрации виден схематичный уровень.
Последующий [аудит масштаба](SCALE_AUDIT.md) выявил несогласованный с Софией
размер нарисованных телефона/ящиков. Совмещение тропинки не подтверждает
верность масштаба ассетов; фон по этому замечанию пока не переделывался.

## Проверки

Свежий итог **2026-10-23: 559/559** в восьми наборах: пикселизация **41**,
нуар **33**, developer **94**, campaign developer **94**, JSON **88**,
переключатели **48**, campaign flow **106**, лесной маршрут **55**.
Реальные **5/5 CFG** неизменны по SHA256. Проверка ресурсов:
**64 медиа / 156 путей / 0 ошибок**. В двух developer-наборах ожидаемая
ошибка повреждённого временного CFG; других ошибок финальных прогонов нет.
Первый лесной прогон **52/55** выявил устаревший тестовый ввод: он не делал
повторного нажатия прыжка после хвата. Исправлен только драйвер теста согласно
действующему управлению; повтор **55/55**. Оба журнала сохранены в отчёте.

Нативная проверка [pixel_filter_smoke.gd](../tests/pixel_filter_smoke.gd):
UI и сохранение, независимость фильтров, реальные блоки 8/2 px, возврат
исходных пикселей при размере 1, чёткий UI, сочетание монохрома с красным,
размер окна 1600×900/1280×720, положение исходной тропинки и наличие прежнего пола.
[Снимки и журналы](../../../../5_Проверки%20и%20отчёты/Полигон/core/pixel_filter_20261023/).
Снимки просмотрены; они не являются новыми утверждёнными художественными эталонами.
Контроль профилей и журналы находятся в отчёте рядом со снимками.
Комфорт длительной игры и производительность разных GPU не проверялись.
