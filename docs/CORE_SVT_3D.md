13.11.2026, явное поручение пользователя. Подключён источник
101_3D Модели оружия/СВТ (низкопилигональная, нейронная).glb,
копия resources/core/weapons_3d/SVT40.glb и импортированные материалы.
Одна сетка, 33130 вершин; исходник не изменён. Игровая длина 1.226 м,
равномерный масштаб 1.226/1.196132, ориентация согласована после Godot-импорта.
Дуло (.941,0,0), рукоять (.09,−.035,.020), поддержка (.32,−.02,−.020),
приклад (−.288,−.065,0). Модель смещена (.30,−.18,0).

Выбор СВТ в меню/слот 1 включает модель, слот 2 остаётся пистолетом.
Баланс/боезапас/звук/темп СВТ не менялись. Native mount, выстрел/луч
используют реальную ось pivot для всех четырёх моделей, включая пистолет.
Магазин СВТ является частью единой сетки: прежний proxy-drop сохранён
для reload; сам магазин из новой сетки пока не вырезан. Обычная стойка
больше не показывает лишний proxy. Полноценная отдельная анимация затвора
и настоящего магазина этим подключением не добавлена.

Большие пальцы: thumb1/2/3 решаются к действительной мировой точке хвата
после коррекции досягаемости, вместо фиксированного локального поворота.
Это устраняет зависимость направления от верхнего/нижнего наведения.
Не означает художественную приёмку всех пальцев/всех поз.

1911: исходная skin содержит joint_bullet_05 — собственный анимированный
патрон, дублировавший игровую гильзу и остававшийся под пистолетом.
pistol_mesh_3d создаёт runtime ArrayMesh с теми же атрибутами/весами/
материалами, исключая 480 треугольников этой кости. Источник/skin/Fire
не перезаписываются. Игровые гильзы и их звук/физика не удалялись.

Проверки Windows Godot 4.7.2: SVT_THUMB_PISTOL failures=0 (четыре оружия,
четыре направления, близость большого пальца к действительному хвату,
подключение СВТ, исключение патрона). WEAPON_LOADOUT на шести маршрутах,
меню 3D/2D, lifecycle магазинов, FX 82, RIGHT_SHOULDER 4211 — failures=0/PASS.
Runtime media errors=0. Оконные СВТ: ADS/от бедра/переноска с обеих сторон
и три четверти. Внешняя папка: svt_integration_2026-11-13 в проверках Полигона.
FPS-прогон/Windows экспорт не выполнялись. Кампания остаётся 2D.
