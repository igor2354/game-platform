# Пролог I: отдельное небо и проплывающие облака

## Статус — 2026-11-08

По поручению пользователя сгенерированы два независимых слоя и подготовлен
анимированный **кандидат на всю локацию 246 м**, вместо отдельных небес по
экранам. В обычный запуск/билд новый арт не включён: явного утверждения
полученного результата ещё нет. Исходные runtime-ресурсы, камера, герой,
геометрия, сохранённые профили и нынешние эффекты не менялись.

Медиатека: `2_Локации/Фоны/Пролог_1_Небо_2026-11-08/`, логический путь
`docs/prologue1_sky` в `tools/media_paths.json`. Внутри — исходный стилевой
референс, PNG-кандидаты, промпты ImageGen, код, нативные кадры, APNG и
автономный `preview.html`. Все генерации сделаны встроенным image_gen;
исходные RGBA/альфа сохранены без перекраски и растровой дорисовки.

## Слои и движение

- `Кандидаты/Слои/sky_base.png`: непрозрачная живописная атмосфера2172×724,
  холодная ночная палитра по текущему лесу. Без ландшафта/построек/растений,
  луны и дополнительных ориентиров. Неподвижна в координатах локации.
- `Кандидаты/Слои/clouds_v1.png`: реальные RGBA2172×724, облака и прозрачные
  промежутки. Два плана из одного источника, разные периоды/фазы/высоты.
  Дальние облака движутся вправо8 ед./с, ближние16 ед./с при множителе1.
  Пауза и скорость0 сохраняют текущую фазу; смена скорости не телепортирует
  облака. Переносится рисунок вместе с контуром/альфой, не маска цвета.

`tools/prologue1_sky_candidate.gd` и одноимённый shader создают отдельный
узел за задниками. Плоскость фиксирована: от −4200 до длины маршрута+4200
по X и −4600…4800 по Y относительно начала локации. Никакого чтения
камеры для размещения. Используется один quad/два исходных изображения,
а не гигантская текстура на весь мир или набор разных небес по экранам.
UV облаков циклический; прозрачная зона стыка предотвращает обрезанный
силуэт. Основа имеет непрерывное зеркальное продолжение по X. Камера
просматривает эту фиксированную область, движутся только облака.

В текущих первых двух фоновых рисунках небо впечено. Поэтому в **кандидатном
превью** старый NightForestBackground временно скрыт, чтобы сравнить новое
небо с неизменённым игровым планом по всей карте. Это не новая версия лесного
задника и не его отключение в обычной игре. Подключение нового неба должно
учесть прозрачные просветы лесного слоя; поверх старого непрозрачного неба
новый слой накладывать нельзя. Луну/дым/огонь не переносили в облачную ленту.

`preview.html` содержит те же PNG внутри файла и непрерывную анимацию:
пауза, множитель скорости, плотность, выключение основы/каждого облачного
плана, обзор0…246 м и вся панорама. Это параметры просмотра, не CFG игры.
APNG — один 12-секундный фрагмент из72 кадров Godot,960×540; не отдельный
игровой спрайт-лист. В HTML движение не ограничено длительностью клипа.

## Фактическая проверка

Mac, Godot4.7.2, GL Compatibility, запуск через `run.command`:
`tools/preview_prologue1_sky.gd` — **126/126**, включая сохранение кадров.
Проверены12 точек2…244 м при zoom0,7, постоянный мировой трансформ,
покрытие видимой области, zoom0,5/3 в конце, неизменность геометрии и
регистрации игрового слоя. Отдельный буфер: неподвижная основа совпадает
пиксель в пиксель в двух фазах, облачные контуры меняются, RGBA-прозрачность
сохраняется; пауза/продолжение, изменение скорости без скачка, остановка
в текущей фазе. Журнал без SCRIPT ERROR/ERROR/FAIL.

72 декодированных кадра APNG совпали с исходными нативными кадрами побайтно.
В браузере открыты и проверены пауза, точка246 м и обзор всей локации,
затем возвращены движущиеся облака у8 м. PNG, блокинг и5 реальных CFG
неизменны по SHA256 —23 защищённых файла. Все пять путей профилей в
Godot-превью изолированы во временном каталоге.

Это техническая проверка кандидата. Полного прохождения, приёмки нового
арта, интеграции в обычную игру, экспорта и замера FPS не было.
